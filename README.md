## 📖 About The Project

<img src="Micro%20Podcast%20Website/assets/images/desktop.png" alt="Micro Desktop Screenshot" width="100%"/>
<img src="Micro%20Podcast%20Website/assets/images/mobile.png" alt="Micro Mobile Screenshot" width="100%"/>

**Micro Podcast Website** is a modern and responsive podcast platform concept designed to showcase podcast shows and audio-focused content through an engaging and visually appealing interface.

The layout focuses on:

- Modern and creative podcast-focused visual design
- Clear presentation of podcast content
- Media-centric imagery and visual hierarchy
- Responsive layouts for desktop and mobile devices
- Clean typography and balanced spacing

This project demonstrates the ability to build **modern media-focused websites**, create engaging content layouts, and deliver responsive interfaces with a polished user experience.

Ideal for:

- Podcast platforms and creators
- Audio streaming websites
- Media and entertainment brands
- Personal podcast portfolios
- Front-end UI and responsive design practice
